# ASCEND Progressive Overload Logic — v1.0.1

ASCEND uses performance-gated double progression.

- The current load stays in place while the operator adds clean reps across the prescribed working sets.
- A load increase is recommended only when every prescribed working set reaches the top of the exercise's rep range.
- There is no deadline for achieving the recommendation.
- One weaker session does not reduce the target. ASCEND asks the operator to recover the previous standard first.
- A plateau requires four exposures at the same load without improvement in total reps or estimated strength.
- Exercise alternatives are suggested only after a confirmed plateau; they are never rotated randomly.

Example for 3 sets of 8–12 at 55 kg:

- 8/8/8 → next milestone: 25 total reps at 55 kg
- 9/8/8 → next milestone: 26 total reps at 55 kg
- 12/12/12 → load increase earned; next milestone: 57.5 kg × 8

The recommendation is a destination, not a deadline.
